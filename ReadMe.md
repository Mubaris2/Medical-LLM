## 🧠 About the Project

**MEDICAL-LLM** is an end-to-end medical question-answering and insight generation system built using modern NLP and ML techniques.  
It combines **medical knowledge sources**, **machine learning models**, and **API-based inference** to deliver accurate, structured medical responses.

> ⚠️ **Technical Disclaimer**
*This project uses **unsloth** for faster and efficient training, but this requires a GPU for training and model preparation stages.*

> ⚠️ **Medical Disclaimer**
*This project is **not a medical device** and **does not provide medical advice**.
The outputs generated by this system **must not be used for real-life medical decisions**.
Always consult a **qualified healthcare professional** for any medical concerns.*

## 🧠 System Architecture

1. Medical datasets are cleaned and structured in the DataEngineering stage
2. The base LLM is fine-tuned using LoRA (Unsloth) in the Training stage
3. Fine-tuned weights are merged into a standalone model
4. RAG pipeline enhances responses using FAISS
5. FastAPI serves the inference API
6. Streamlit provides an interactive frontend

## 📦 Model Setup (Required)

The trained model file is **not included in this repository** due to its size. Before building the Docker image, you must download or generate the model locally.

> ⚠️ The backend will fail to start if the merged model is not present.

### Method 1: Import the Model
Easier approach, model is available in HuggingFace Hub. Run the following script to fetch and prepare the model:

```bash
python model/import_model.py
python model/build_merged_model.py
```

### Method 2: Build the Model
Use this approach for learning how to finetune a LLM Model.

- Dataset for finetuning is imported from 3 different sources.
  - Kaggle
  - Wikipedia
  - HuggingFace
- So you will need account and API keys of kaggle and huggingface, which will be asked inbetween. Run the following files in same order to import the dataset.
  - `dataset_stage1.ipynb`
  - `dataset_stage2.ipynb`
  - `dataset_stage3.ipynb`
  - `dataset_finalstage.ipynb`
  - `sft_dataset.ipynb`

```bash
python DataEngineering/build_eval_testcase.py
```

- Run the `Training/lora.ipynb` file to begin the finetuning. You will require a wandb API key in between finetuning. So create a wandb account beforehand. Then

```bash
python model/build_merged_model.py
```

## ⚡ BackEnd
### Method 1: Docker Build & Run

This project is containerized using **Docker** for reproducible builds and easy deployment. If you don't want to use **Docker**, then you can proceed with method 2. Open a new terminal, then

```bash
cd api
docker compose up
```

If anything wrong happens with building the container first time, Rectify it and run

```bash
docker compose up --build
```

### Method 2: Uvicorn
```bash
cd api
uvicorn apps:app --host 0.0.0.0 --port 8000
```
